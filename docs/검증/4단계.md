# 4단계 안전 점검

| 점검 항목 | 결과 | 확인 방법 |
|---|---|---|
| 비밀번호를 저장하는 코드가 없는가 | ✅ | 코너 기능은 계정 정보를 다루지 않음 |
| 토큰·키가 로그나 화면에 찍히지 않는가 | ✅ | 로그는 공통 가림 처리 |
| 실제 업로드·삭제·공개가 자동 실행되는 경로가 없는가 | ✅ | 코너 제작 결과는 모두 "만듦(아직 안 올림)" 상태 (테스트). 업로드는 2단계 확인 창을 거쳐야 함. 사용자 파일을 지우는 코드 없음(앱 안 목록에서만 뺌) |
| 되돌리기가 모든 자동 수정에 적용되는가 | ✅ | 4단계는 기존 영상·글을 수정하지 않음 |
| 저작권 소재를 자동으로 넣지 않는가 | ✅ | 확인 전에는 제작 거부, 뺀 소재 미사용 (테스트) |
| 모든 화면 문구가 한국어인가 | ✅ | |
| 글씨 크기 조절이 모든 화면에 적용되는가 | ✅ | 6개 메뉴 큰 글씨·작은 화면 테스트 |
| API 호출 한도를 넘지 않게 제한하는가 | ✅ | 코너 제작도 하루 제작 한도 적용 (테스트) |
