# 3단계 안전 점검

| 점검 항목 | 결과 | 확인 방법 |
|---|---|---|
| 비밀번호를 저장하는 코드가 없는가 | ✅ | 구글 블로그는 OAuth 토큰(보안 저장소). 티스토리는 로그인 정보를 받지 않음 |
| 토큰·키가 로그나 화면에 찍히지 않는가 | ✅ | 1단계와 같은 로그 가림 처리를 거침 |
| 실제 업로드·삭제·공개가 자동 실행되는 경로가 없는가 | ✅ | `BloggerApi` 에 삭제·게시(공개) 기능 없음. 새 글은 `isDraft=true` 로만(테스트: 상태 DRAFT 유지). 티스토리는 자동 게시 없음(테스트: API 호출 0회). 자동 작업은 기존 글 제목·라벨 다듬기만(되돌리기 가능) |
| 되돌리기가 모든 자동 수정에 적용되는가 | ✅ | 블로그 수정도 같은 수정 내역(EditLog)에 원본 먼저 기록, 화면에 되돌리기 버튼, 테스트로 원상복구·충돌·중복 확인 |
| 모든 화면 문구가 한국어인가 | ✅ | |
| 글씨 크기 조절이 모든 화면에 적용되는가 | ✅ | 큰 글씨·작은 화면 테스트에 "블로그" 메뉴 포함 |
| API 호출 한도를 넘지 않게 제한하는가 | ✅ | 하루 수정 개수·새 글 개수 제한, 자동 재시도는 최대 3회 |
