# 2단계 안전 점검

| 점검 항목 | 결과 | 확인 방법 |
|---|---|---|
| 비밀번호를 저장하는 코드가 없는가 | ✅ | 힉스필드는 API 키(보안 저장소), 피그마는 OAuth 토큰(보안 저장소). 도구 비밀번호 입력칸 자체가 없음 |
| 토큰·키가 로그나 화면에 찍히지 않는가 | ✅ | 키 입력칸 가림, 저장 후 다시 보여 주지 않음. 테스트: 해제 후 보안 저장소에서도 지워짐 |
| 실제 업로드·삭제·공개가 자동 실행되는 경로가 없는가 | ✅ | `uploadPrivate` 는 `userConfirmed: true` 없이는 거부(테스트). 화면의 확인 창에서만 true. 자동 작업 실행기는 업로드를 부르지 않음(테스트: 다음 날 실행 후 업로드 0회). 업로드는 항상 private(테스트). 공개 전환·삭제 기능 없음. 힉스필드 크레딧 사용도 `userApproved: true` 필수(테스트) |
| 되돌리기가 모든 자동 수정에 적용되는가 | ✅ | 2단계는 기존 영상을 수정하지 않음(새 비공개 영상만). 기존 수정 경로는 1단계 그대로 |
| 모든 화면 문구가 한국어인가 | ✅ | 새 문구는 strings.dart 와 화면 코드에 한국어로 |
| 글씨 크기 조절이 모든 화면에 적용되는가 | ✅ | 앱 전체 적용 구조 그대로. 큰 글씨·작은 화면 테스트에 "제작" 메뉴 포함 |
| API 호출 한도를 넘지 않게 제한하는가 | ✅ | 업로드 전 남은 한도(1,600) 확인, 모자라면 호출하지 않고 내일로(테스트). 하루 제작 한도 |
