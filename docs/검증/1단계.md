# 1단계 안전 점검

| 점검 항목 | 결과 | 확인 방법 |
|---|---|---|
| 비밀번호를 저장하는 코드가 없는가 | ✅ 통과 | 로컬 계정은 PBKDF2 해시만 저장 (`core_test: 비밀번호는 저장하지 않고 해시만 저장`). 구글·피그마는 OAuth 로 비밀번호를 앱이 보지 않음. 코드 검색으로 비밀번호 저장 경로 없음 확인 |
| 토큰·키가 로그나 화면에 찍히지 않는가 | ✅ 통과 | 모든 로그는 `redact()` 를 거침 (Bearer, ya29., 1//, sk-ant-, GOCSPX-, AIza, key=value, 이메일). 테스트 `민감정보 가리기`, `문제 신고 파일에는 비밀 정보가 없다`. API 키 입력칸은 가림 처리, 저장 후 내용을 다시 보여 주지 않음. 키는 설정 DB 가 아니라 보안 저장소에만 (`ai test`) |
| 실제 업로드·삭제·공개가 자동 실행되는 경로가 없는가 | ✅ 통과 | `YouTubeApi` 에 삭제·공개 전환 기능 자체가 없음 (테스트로 소스 검사). 제목 수정은 `part=snippet` 만 보내 공개 범위를 못 바꿈 (테스트). 업로드는 `privacyStatus: private` 고정 (테스트). 자동 작업 실행기에 업로드 경로 없음 (`uploadCalls == 0` 테스트). 음성 "공개로 바꿔"·"삭제해" 는 안내만 (테스트) |
| 되돌리기가 모든 자동 수정에 적용되는가 | ✅ 통과 | 유일한 수정 경로 `EditService.apply` 가 반영 전에 원본을 기록. 수정 내역 화면에 모든 "수정됨" 항목에 되돌리기 버튼. 되돌리기 테스트 8개 |
| 모든 화면 문구가 한국어인가 | ✅ 통과 | 화면 문구는 `lib/core/strings.dart` 한 곳에 모음. 오류 안내는 모든 실패 종류에 한국어 + 영문 코드 노출 없음 (테스트) |
| 글씨 크기 조절이 모든 화면에 적용되는가 | ✅ 통과 | `MaterialApp.builder` 에서 모든 화면에 한 번에 적용. 아주 큰 글씨(1.6배) + 작은 화면 테스트로 모든 메뉴 확인 |
| API 호출 한도를 넘지 않게 제한하는가 | ✅ 통과 | 유튜브: 호출 전 `QuotaTracker.reserve` 로 미리 차감, 모자라면 호출하지 않음 (테스트). 한도 초과 응답 시 오늘 한도 0. 하루 기준은 태평양 시간 자정 (테스트). AI: 예상 비용이 월 한도를 넘으면 호출하지 않음 (테스트) |
