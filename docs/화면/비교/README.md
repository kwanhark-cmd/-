## 점검표: 가장 먼저 눈에 띄는 요소가 가장 중요한 요소인가

| 화면 | 가장 중요한 것 | 전 | 후 |
|---|---|---|---|
| 홈 | 오늘 할 일 | ✗ 같은 어두운 테두리 상자 중 하나. 아래 원형 게이지 상자가 더 크게 보임 | ✓ 가득 찬 폭, 가장 큰 카드, 상태 색(노랑)으로 채움, 큰 3D 그림 |
| 홈 | 채널·제작 | ✗ 같은 크기 상자 6개가 세로로 나열 | ✓ 2열 중간 크기, 파랑·보라 타일, 큰 숫자 |
| 홈 | 사용량·비용 | ✗ 원형 게이지 두 개가 한 화면을 차지 | ✓ 작은 띠 하나에 큰 숫자 두 개 + 얇은 막대 |
| 채널 현황 | 채널 이름·상태 | △ 굵은 초록 테두리가 이름보다 먼저 보임 | ✓ 큰 썸네일(160) + 큰 이름, 상태는 왼쪽 띠와 배지, 숫자 3개는 아이콘과 한 줄 |
| 설정 | 연결 상태·문제 신고·업데이트 | ✓ 맨 위 | ✓ 맨 위 그대로 |
| 설정 | 항목 찾기 | ✗ 같은 상자 10개 나열 | ✓ 색 머리가 있는 묶음 5개 (계정 연결·인공지능·자동 작업·보기와 듣기·자료 관리) |
| 설정 | 모두 지우기 | △ 다른 버튼들 사이 | ✓ 맨 아래 빨간 카드에 따로 |
| 제작·블로그·내 코너 | 시작 버튼 | ✓ 주황 큰 버튼 | ✓ 그대로, 안내 말풍선은 테두리 없는 채운 카드 |

## 그 밖의 원칙 확인
- 테두리는 선택·상태 표시(끊긴 채널의 빨간 테두리, 고대비 모드)에만. 나머지는 채운 카드 + 부드러운 그림자.
- 어두운 모드에서 카드는 바탕보다 한 단계 밝고, 영역 타일은 중간 채도 (어두운 바탕 위 어두운 상자 없음). 대비는 `app/test/redesign_test.dart` 가 4가지 테마 모두 4.5:1 이상인지 확인.
- 글씨 5단계 (큰 숫자 34 / 제목 26 / 묶음 21 / 본문 17 / 작은 글 15), 카드 사이 간격 24 (예전 16의 1.5배).
- 같은 크기 상자 3개 이상을 한 줄에 놓지 않음 (넓은 화면에서도, 테스트로 확인).

다시 만들기: `cd app && SHOTS=1 flutter test --run-skipped --tags tool test/tool_screens_test.dart` 뒤 이 폴더의 합치기 순서대로.
