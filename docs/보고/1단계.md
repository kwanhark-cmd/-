# 1단계 보고 — 뼈대 + 유튜브 채널 관리

## 만든 것
- **앱 뼈대**: Flutter 로 안드로이드·윈도우·맥(·리눅스) 한 코드. 한국어 글꼴(Noto Sans KR) 포함.
- **로그인(여러 사용자)**: 기기 안 로컬 계정. 사용자마다 자료 파일이 따로 있어 서로의 채널·자료가 보이지 않음. 비밀번호는 저장하지 않고 되찾을 수 없는 해시만 저장.
- **첫 실행 안내**: 언어·글씨 크기 → 마이크·알림·파일 권한(거부해도 동작) → 계정 연결(건너뛰기 가능) → 연습 모드 안내.
- **채널 등록**: 채널 주소 + "구글로 연결". 구글 창에서 직접 로그인하고 앱은 토큰만 받음(기기 보안 저장소). 같은 계정의 채널은 한 번에 등록. 채널별 연결 해제.
- **채널 현황**: 모든 채널의 구독자·영상 수·조회수, 영상 제목·설명·키워드·조회수. 영상 목록은 30개씩 나눠서 보여 줌(수천 개여도 느려지지 않음). 음성으로 요약 듣기.
- **채널 스타일 카드**: 영상 제목·설명을 분석해 분위기·말투·주제·제목 스타일·시청자를 저장. 직접 고칠 수 있음.
- **기존 영상 자동 수정**: 제목·설명·키워드. 바꾸기 전 원본을 먼저 기록, 버튼 하나로 되돌리기, 하루치 모두 되돌리기. 기본 채널당 하루 2개, 처음 한 달은 최대 3개. 수정 전후 조회수 비교.
- **매일 수정 요약**: 화면 + 음성.
- **음성 기능**: 마이크 버튼(모든 화면), 글자 입력으로도 가능. 음성 명령, 읽어주기(켜기/끄기·속도), 음성 메모, 아침 브리핑(정한 시간). 중요한 명령은 화면·음성으로 다시 확인. 공개 전환·삭제는 앱이 하지 않고 안내만.
- **유튜브 하루 한도**: 남은 한도 표시, 넘는 작업은 멈추고 다음 날로. 한도 초과 응답을 받으면 오늘 한도를 0으로 처리.
- **AI 연결**: Claude API 키(보안 저장소), 모델 선택, 예상 비용, 이번 달 누적, 월 한도(도달 시 자동 작업 중지·연습 모드). 키가 없으면 연습 모드.
- **자동 작업 실행기**: 기본 꺼짐. 켜면 정한 시간대에 하루 한 번(채널 새로 불러오기 → 영상 다듬기). 시작·끝 알림. 윈도우·맥에서만. 진행률·취소 버튼. 업로드·삭제·공개는 하지 않음.
- **오류 대비**: 모든 외부 호출에 시간 제한 + 재시도 3회(간격 늘림). 토큰 만료·권한 취소·한도 초과·인터넷 끊김을 구분해 "다시 연결 / 내일 다시 / 다시 시도" 안내. 전역 오류 처리, 기기 안 로그(민감정보 자동 제거), 문제 신고 파일 만들기.
- **자료 관리**: 자료 형식 버전 + 자동 변환(변환 전 자동 백업), 백업·복원, 초기화(2번 확인), 앱 버전·변경 내역.
- **자동 빌드**: GitHub Actions 로 push 할 때마다 테스트 + 윈도우·맥·안드로이드·리눅스 빌드.

## 테스트한 방법과 결과
- 단위 테스트 68개 + 화면 흐름 테스트 3개 = **71개 모두 통과** (`flutter test`)
  - 되돌리기: 정확한 원상복구, 두 번 눌러도 안전, 같은 영상 여러 번 수정 시 최근 것부터, 사용자가 유튜브에서 직접 바꾼 경우 확인 없이 덮어쓰지 않음, 되돌리기 중 인터넷 끊김, 하루치 모두 되돌리기
  - 흐름 테스트(연습 모드, 휴대폰 화면, 큰 글씨): 새 사용자 → 첫 실행 안내 → 채널 등록 → 현황 → 스타일 분석 → 제목 수정 → 되돌리기 → 음성 명령(글자·마이크) → 아침 브리핑
  - 아주 큰 글씨 + 작은 화면에서 모든 메뉴 끝까지 스크롤하며 화면 잘림 오류 없음 (이 테스트로 실제 잘림 1건을 찾아 고침)
- 정적 검사 `flutter analyze --fatal-infos`: 문제 0개. 형식 검사 통과.
- 리눅스 정식 빌드(`flutter build linux --release`) 성공.
- 외부 API 는 모두 가짜 응답으로 테스트. 테스트 중 실제 인터넷 호출이 일어나면 테스트가 실패하도록 막아 둠.
