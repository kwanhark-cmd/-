# 4단계 보고 — 사용자 코너

## 만든 것
- **"내 코너" 메뉴**: 코너 이름과 올릴 채널을 사용자가 정함 (예: "사장님의 하루" → 요리 채널).
- **소재 넣기**: 내가 찍은 영상 넣기 / 음성 메모 고르기 / 이야기 글로 쓰기 / **폴더에서 소재 가져오기**.
- **자동으로 만들기**: 소재로 자막(SRT 파일)·제목·설명·키워드·썸네일 문구·대본을 형식별(쇼츠·롱폼·다큐·사진 게시물·음성 대화형 중 선택)로 한 번에. 직접 찍은 영상은 영상 형식에 자동으로 붙음. 만든 것은 "제작" 메뉴로 가서 확인 후 비공개로 올림(자동 업로드 없음).
- **저작권 확인**: 파일 이름이 방송·드라마·영화·MV·내려받은 영상처럼 보이거나, 폴더에서 가져온 소재에 출처 설명이 없으면 "저작권 확인 필요"로 표시. 사용자가 "사용해도 돼요 / 빼 주세요" 를 정하기 전에는 만들지 않음.
- **3번·4번 앱 연동 공통 형식**: 폴더에 파일과 `manifest.json`(출처 앱, 제목, 설명, 저작권 정보)을 넣으면 그대로 가져옴. 형식은 `app/lib/features/corner/material_source.dart` 맨 위 설명 참고.

## 테스트한 방법과 결과
- 새 테스트 7개 + 화면 흐름 1개 → **전체 100개 통과**
  - 저작권 의심 파일 이름 짐작, manifest.json 읽기(3·4번 앱 연동)
  - 저작권 확인 전에는 만들지 않음, 뺀 소재는 쓰지 않음
  - 영상 + 음성 메모 → 3가지 형식, 자막 파일 생성, 모든 결과는 "아직 안 올림" 상태
  - 하루 제작 한도, 코너 이름·채널 필수
  - 1단계 자료(v1)를 최신(v4)으로 자동 변환 + 자동 백업 + 자료 보존
  - 화면 흐름: 코너 만들기 → 의심 영상 넣기 → 저작권 확인 창 → 자동 제작
  - 작은 화면 + 아주 큰 글씨로 6개 메뉴 모두 잘림 없음
- 정적 검사 0개, 형식 검사 통과, 리눅스 빌드 성공
