# 3단계 보고 — 블로그·티스토리 관리

## 만든 것
- **"블로그" 메뉴**
  - **구글 블로그 연결**: 구글로 연결하면 그 계정의 블로그를 모두 등록. 글을 20개씩 나눠 불러옴.
  - **블로그 스타일 카드**: 글을 분석해 분위기·말투·주제를 저장, 직접 수정 가능.
  - **기존 글 다듬기**: 제목·라벨을 자동 수정. 바꾸기 전 원본 기록, 글마다 "되돌리기". 블로그에서 직접 바꾼 글은 확인 없이 덮어쓰지 않음. 하루 수정 개수 제한(첫 한 달 최대 3).
  - **새 글**: 블로그 스타일에 맞춰 글을 써서 구글 블로그에 **초안(비공개)**으로 올림. 하루 1~2개. "구글 블로그에서 열기"로 확인 후 사용자가 직접 공개.
  - **티스토리**: 이름·주소만 등록. 글을 완성하면 "제목 복사 / 본문 복사 / 태그 복사" 버튼. 자동 게시는 하지 않음.
- **자동 작업 실행기**가 켜져 있으면 블로그 글 불러오기·다듬기도 함께 함.
- **아침 브리핑**에 확인 기다리는 블로그 새 글 수 추가.

## 테스트한 방법과 결과
- 새 테스트 6개 + 화면 흐름 1개 → **전체 92개 통과**
  - 연결·불러오기·분석, 자동 수정·하루 한도·되돌리기·충돌 확인·두 번 되돌리기
  - 새 글은 초안으로만(공개 상태 아님), 하루 한도, 티스토리는 복사만(블로그 API 호출 0회)
  - 자동 작업 실행기 연동, 유튜브 재연결 때 블로그 계정이 지워지지 않음(이 테스트로 실제 버그를 미리 막음)
  - 연결 실패 시 계정이 남지 않음
  - 화면 흐름: 티스토리 추가 → 새 글 → 본문 복사(클립보드 확인)
- 정적 검사 0개, 형식 검사 통과, 리눅스 빌드 성공
