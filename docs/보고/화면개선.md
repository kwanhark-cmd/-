# 화면 개선 보고 (디자인·3D)

기능은 그대로 두고, 처음 쓰는 분과 어르신도 설명 없이 쓸 수 있게 화면을 바꿨습니다. 기존 테스트 104개는 하나도 고치지 않고 모두 통과하며, 새 검증 테스트 9개를 더했습니다 (총 113개).

## 바뀐 것

### 색 (테마 한 파일: `app/lib/ui/theme.dart`)
- 주요색(남색) 1개, 강조색(주황) 1개, 상태색 4개: **초록 = 완료·연결됨, 파랑 = 진행 중, 노랑 = 확인 필요, 빨강 = 문제·주의**. 앱 어디서나 같은 뜻은 같은 색.
- 모든 버튼에 색이 있음 (회색 글자 버튼 없음). 주요 동작은 주황, 보조 동작은 옅은 남색, 위험 동작(삭제·초기화·전체 되돌리기·연결 해제)은 빨강 바탕.
- 밝은 모드·어두운 모드·**또렷하게 보기(고대비)** 모드. 설정 → 보기에서 고름.
- 색만으로 뜻을 전하지 않도록 상태 배지에 항상 아이콘 + 글자를 함께 씀.
- 연습 모드 띠는 노랑(확인 필요).

### 모양과 크기
- 버튼 높이 56 이상, 누르는 곳 48 이상, 모서리 둥글기 16, 넉넉한 간격 — 모두 테마 값.
- 버튼·타일에 그림자와 두께(아래쪽 어두운 면)로 입체감. 누르면 살짝 눌리고 떼면 튀어 오름.
- **홈**을 큰 3D 타일 6개로: 채널 현황 / 콘텐츠 만들기 / 확인 대기 / 블로그 / 내 코너 / 설정. 타일마다 3D 아이콘 + 짧은 이름 + 한 줄 설명 + 상태 배지.
- 남은 유튜브 사용량과 이번 달 인공지능 비용을 **원형 게이지**로.
- **채널 목록**은 썸네일 중심 큰 카드. 테두리 색이 연결 상태(초록 연결됨 / 빨강 끊김), 확인 대기 영상은 노랑 배지.
- 긴 목록(영상·수정 내역·제작·블로그·메모)은 왼쪽 상태 색 띠가 있는 가벼운 평면 카드.
- 글씨 크기 3단계(보통·크게·아주 크게)를 고르면 모든 화면에 즉시 적용.

### 3D 아이콘과 마스코트 (`app/assets/icons3d`)
- Microsoft Fluent Emoji 3D(MIT 라이선스) 중 필요한 33개만 넣음 (256px PNG, 라이선스 파일 동봉).
- 앱 전용 **비서 마스코트**(헤드셋을 쓴 로봇) 5가지 표정: 인사·작업 중·완료·주의·축하. 홈 인사, 아침 브리핑 인사, 작업 진행 창, 오류 안내, 완료 축하, 음성 창에 상황별로 나옴.
- 모든 그림은 한 폴더에 있어 파일만 바꾸면 그림이 바뀜. 전체 약 1.2MB (목표 10MB 이하).
- 3D 엔진은 쓰지 않음. 그림자·두께·눌림 효과와 3D 그림으로 입체감.

### 움직임
- 버튼 눌림·튀어오름, 화면 전환 250ms, 목록이 순서대로 살짝 올라오며 나타남(처음 몇 개만), 확인 대기·끊김 배지는 한 번 흔들림, 원형 게이지가 차오름, 완료 시 체크 + 마스코트 축하.
- 설정 → **움직임 줄이기**를 켜면 모든 움직임이 꺼짐 (기기 설정의 "애니메이션 줄이기"도 따름).
- 설정 → 누를 때 진동·소리 켜고 끄기.

### 초보자 편의
- 홈 맨 위 **"오늘 할 일"** 카드 하나: 확인 대기 영상 → 없으면 연결 끊김 → 만료 임박 → 채널 없음 순서. 큰 버튼 하나로 바로 이동.
- 모든 하위 화면의 같은 자리에 "뒤로"(왼쪽 위)와 "처음 화면"(오른쪽 위, 집 모양) 버튼, 큰 제목.
- 처음 쓰는 화면(채널·수정 내역·제작·블로그·내 코너)에 말풍선 안내. "알겠어요"를 누르면 다시 안 나오고, 설정 → "처음 사용 안내 다시 보기"로 다시 볼 수 있음.
- 위험 동작은 2단계 확인 (삭제, 전체 되돌리기, 연결 해제, 초기화).
- 되돌리기 버튼을 주황(주요 동작)으로 눈에 띄게.
- 빈 화면에 "아직 없어요" + 어떻게 시작하는지 + 큰 시작 버튼.
- 화면 문구 전수 점검: 인공지능(AI), 연결 열쇠(API 키), 구글 앱 번호(클라이언트 ID), 사용권(크레딧), 달러 등 쉬운 말로 바꿈 (다른 사이트에서 찾아야 하는 말만 괄호로 남김).

## 검증
- 기존 테스트 104개 그대로 통과 + 새 테스트 9개:
  - 대비: 밝음·어두움·고대비 밝음·고대비 어두움 4가지 모두 글자/바탕, 버튼, 상태 배지가 4.5:1 이상
  - 가장 작은 화면(320×568) + 아주 큰 글씨 + 어두운 모드, 그리고 고대비 어두운 모드에서 아래 메뉴 6개 + 하위 화면 8개 + 첫 실행 안내 4단계 + 로그인 화면을 끝까지 내려 보며 잘림·겹침 없음
  - 움직임 줄이기: 움직임 시간 0, 목록 나타나기 효과 꺼짐, 설정이 앱 전체에 반영
- 이 테스트들이 실제 문제를 찾아 고침: 떠 있는 알림이 버튼을 가림, 아주 큰 글씨에서 고르기 막대·선택 상자가 넘침, 고대비 어두운 모드에서 빨강 버튼 글자 대비 부족
- 린트·형식 검사 통과, 리눅스 빌드 성공

## 속도 (화면 개선 전후)
테스트 환경에서 같은 방법으로 7번씩 재어 중간값, 3회 반복 (`test/tool_perf_test.dart`).

| | 시작 | 메뉴 전환 | 상세 화면 열고 닫기 |
|---|---|---|---|
| 개선 전 | 129 / 138 / 129 ms | 68 / 82 / 67 ms | 173 / 174 / 149 ms |
| 개선 후 | 139 / 132 / 126 ms | 87 / 74 / 80 ms | 156 / 142 / 138 ms |

처음 재었을 때는 시작이 약 200ms, 메뉴 전환이 약 105ms로 **느려졌었습니다.** 원인은 홈을 한 번에 모두 그리는 방식이었고, 화면에 보이는 것만 그리는 목록으로 바꾸고 흔들림·게이지 움직임을 짧게, 긴 목록은 처음 몇 개만 움직이도록 줄여 개선 전과 비슷한 수준으로 맞췄습니다. 메뉴 전환은 여전히 몇 ms 정도 차이가 있지만 사람이 느낄 수 있는 차이(약 100ms)보다 훨씬 작습니다.

## 못 한 것과 이유
- **Lottie 애니메이션 파일**: 라이선스가 확인된 파일을 쓰라는 조건이 있어, 지시서 구현 규칙대로 모든 움직임을 Flutter 기본 애니메이션으로 코드에서 만들었습니다 (DECISIONS 44).
- **실제 기기에서 본 모습**: 화면 사진은 테스트 환경에서 그린 것입니다. 실제 기기에서는 운영체제 글꼴·그림자가 조금 다를 수 있어요.
- "AI 콘텐츠 표시를 확인해 주세요" 한 문구는 유튜브 화면의 표시 이름과 맞추려고 그대로 두었습니다 (DECISIONS 48).
