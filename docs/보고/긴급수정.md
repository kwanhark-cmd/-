# 긴급 수정 보고

실제로 써 보다가 알려 주신 문제 6가지를 화면 재설계 전에 먼저 고쳤습니다. 항목마다 자동 테스트를 붙였습니다 (`app/test/urgent_test.dart`, 15개).

## 1. 메뉴를 오가면 스크롤이 맨 위로 튀던 문제
- **원인**: 앱이 1분마다 자동 작업·브리핑을 확인할 때 메뉴 화면을 통째로 새로 만들고 있었습니다. 새로 만들어지니 보던 위치가 사라졌습니다.
- **고침**: 한 번 연 메뉴 화면은 계속 살려 두고(위치 기억), 1분 확인 때는 내용만 새로 그립니다. 새 자료가 들어와도 보던 위치는 그대로입니다.
- **테스트**: 홈·채널·제작·블로그·설정 화면과 채널 상세 화면에서 아래로 내린 뒤 → 자료 갱신 → 자동 작업 실행 → 다른 메뉴에 갔다 오기를 해도 위치가 같은지 확인.

## 2. "다시 시도"를 누르면 오류(Null check operator...)가 나던 문제
- **원인**: 1번과 같은 원인입니다. 실패 창이 떠 있는 동안 원래 화면이 새로 만들어져 사라졌고, "다시 시도"가 사라진 화면으로 창을 띄우려다 오류가 났습니다.
- **고침**: 1번 수정에 더해, 모든 창·알림·진행 창은 원래 화면이 사라졌으면 앱 전체 화면으로 띄웁니다. "다시 시도"는 실패 창을 닫은 뒤에 실행합니다.
- **테스트**: 연결 실패 → 그 사이 자료 갱신 → "다시 시도" → 오류 없이 연결 창이 다시 뜨고 연결까지 되는지. 이미 사라진 화면으로 실패 창·확인 창·알림을 띄워도 오류가 없는지.

## 3. 처음 실패가 로그에 남지 않던 문제
- **고침**: 사용자에게 보여 주는 모든 실패를 오류 로그에 남깁니다. 구글 연결은 어느 단계에서 실패했는지(로그인 / 연결 정보(토큰) / 채널 목록 / 영상 목록)를 함께 적습니다. 열쇠·토큰 값은 적지 않습니다.
- **테스트**: 채널 목록 단계 실패, 영상 목록 단계 실패가 단계 이름과 함께 기록되는지.

## 4. 채널이 없는 구글 계정·영상이 없는 채널
- **고침**: 채널이 없는 계정이면 오류 창 대신 "이 구글 계정에는 아직 유튜브 채널이 없어요" 안내와 **다른 계정으로 연결** 버튼을 보여 줍니다. 빈 계정은 저장하지 않습니다. 영상이 0개인 채널은 등록하고 "아직 영상이 없는 채널" 이라고 알려 줍니다.
- **테스트**: 두 경우 모두.

## 5. 연습 모드 띠 → 연결 상태 따로 표시
- 화면 위 노란 "연습 모드" 띠를 없앴습니다.
- 홈 인사 아래와 설정 맨 위에 **구글: 연결됨/아직 연결 안 됨**, **인공지능: 연결됨/아직 연결 안 됨**을 따로 보여 줍니다. 열쇠를 저장하거나 지우면 바로 바뀝니다. 누르면 설정으로 갑니다.
- 실제 채널이 하나라도 생기면 연습용 가짜 채널은 목록과 합계에서 숨깁니다. 설정 → **연습 자료 보기**로 다시 볼 수 있습니다 (지우지는 않음).

## 6. 문제 신고를 찾기 쉽게
- 설정 맨 위(연결 상태 바로 아래)에 **문제 신고 파일 만들기** 버튼.
- 모든 오류 창 안에 **문제 신고 파일 만들기** 버튼. 누르면 바로 파일을 만들고 위치를 알려 줍니다.
